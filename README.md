2- faça ele responsivo e com uma UX amigável, moderno, responsivo e profissional com interações na tela conforme passar o mouse e rolar a página

3 -Um design minimalista, clean e elegante, com as cores azul escuro e preto

3 -Estrutura organizada para que eu consiga futuramente adicionar novos projetos e informações com facilidade.
